How to use this booklet

Work through the chapters in order on a tablet or laptop in landscape. Open the admin at https://admin.baseapp.asia. You can also open Resources in the admin to download this PDF and follow the same steps on screen.

What you need from BaseApp first

  1. Login email and temporary password
  2. Shop type: Health & Beauty, Food & Beverage, Retail, or General
  3. Country (sets currency: MY→MYR · TH→THB · SG→SGD · ID→IDR)
Wrong country or category? Ask BaseApp Master Admin to open Vendors → Edit before you add prices.

Chapter 1

Sign in to your shop

  1. Open https://admin.baseapp.asia/login
  2. Enter the email BaseApp sent you
  3. Enter your temporary password
  4. Tap Sign in
  5. You land on POS — that is normal
Tip: Use landscape on a tablet. Pull down on most pages to refresh data.

Quick tour after login

POS Walk-in sales at the counter
Chat LINE / WhatsApp inbox
Reports Sales summary
Bookings / Orders Appointments (H&B) or Grab queue (F&B)

Profile menu (avatar) opens Overview, catalog, Rooms & staff, Settings, Account, and Resources.

Chapter 2

Confirm shop details

  1. Open the profile avatar → Settings
  2. Check Shop name — edit if needed
  3. Confirm the line under the name: Country · currency (example: TH · THB)
  4. Save at the bottom of Settings when you change the name
Country and currency are controlled by BaseApp. Merchants cannot change country themselves.

Chapter 3

Upload your catalog

Profile → Services, Menu, or Products (depends on shop type).

Health & Beauty

  1. Tap into the add form
  2. Name — e.g. Small line tattoo
  3. Category — e.g. Tattoo, Treatments, Add-ons, Packages
  4. Duration in minutes
  5. Price in your shop currency
  6. Deposit (optional — use 0 if none)
  7. Save, then repeat

Food & Beverage

  1. Add each menu item: name, category (Food / Drinks / …), price
  2. Optional: open Customisations for modifiers (ice, size, toppings)
  3. Publish to Grab later from Settings after Grab is connected

Retail

  1. Add products: name, category, price
  2. Sell them from POS
Beta tip: Start with 5–15 items. Enough to train staff without delaying go-live.
Chapter 4 · Health & Beauty

Rooms & staff

  1. Profile → Rooms & staff
  2. Add at least one Artist / therapist (your name is fine)
  3. Add a Room / bay if you use stations
  4. These appear when creating bookings and on the day board

Skip this chapter for F&B and Retail shops.

Then create a practice booking

  1. Open Bookings → New
  2. Customer name + phone
  3. Pick service, artist, room, start time
  4. Create booking
  5. On the day: mark paid / complete from the booking detail
Chapter 5 · Recommended for Thailand

Connect LINE Official Account

A. In LINE Developers

  1. Open https://developers.line.biz
  2. Select your provider → Messaging API channel (or create one)
  3. Copy Channel ID, Channel secret, and a long-lived Channel access token
  4. Webhook URL: https://api.baseapp.asia/v1/webhooks/line
  5. Enable the webhook
  6. Turn off conflicting auto-replies if BaseApp should own the chat

B. In BaseApp Settings

  1. Profile → Settings → LINE Messaging
  2. Paste Channel ID, secret, and access token
  3. Optional: LIFF ID (booking also works by typing menu / book)
  4. Tap Save LINE only (or save the full Settings form)
  5. Confirm status shows token / secret on file

C. Smoke test

  1. From a personal LINE account, add the shop OA
  2. Send menu or book
  3. You should get a package / booking flow
  4. Open BaseApp → Chat — the conversation appears
Nothing arrives? Recheck webhook Enabled, URL exact match, and that ID/secret/token are from the same channel.
Chapter 6 · Optional channels

WhatsApp & Grab Food

WhatsApp (optional)

  1. Settings → WhatsApp / Meta
  2. Copy Callback URL, Flows endpoint, Verify token into Meta Developer → WhatsApp → Configuration
  3. Subscribe to messages
  4. Paste Display phone, Phone number ID, WABA ID, permanent access token into BaseApp
  5. Save
  6. Ask BaseApp to open your shop → Meta → Publish booking Flow

Webhook: https://api.baseapp.asia/v1/webhooks/whatsapp

Grab Food (F&B only)

  1. Finish your Menu in BaseApp first
  2. Settings → Grab → Connect Grab
  3. Open the activation link and finish outlet linking
  4. Paste Grab merchant ID if prompted
  5. Publish menu
  6. New orders appear under the Orders tab
Chapter 7

Your first walk-in sale

  1. Open POS
  2. Tap catalog items into the ticket (adjust qty if needed)
  3. Tap Confirm order / Charge
  4. Choose customer or continue as walk-in
  5. Pay with Cash or QR
  6. Finish — optionally send a WhatsApp receipt if WA is connected
QR / pay links may be demo-style in beta unless BaseApp told you otherwise — still practice the full flow.

First-week checklist

  • ☐ Signed in successfully
  • ☐ Shop name looks right; currency matches country
  • ☐ At least 5 catalog items added
  • ☐ (H&B) At least 1 artist (+ room if needed)
  • ☐ LINE connected + menu / book test works
  • ☐ One POS cash sale completed
  • ☐ (H&B) One manual booking created
  • ☐ (Optional) WhatsApp saved + Flow published by BaseApp
  • ☐ (F&B) Grab connected + menu published
  • ☐ Language set for staff who use the tablet
